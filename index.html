💡 What is an Instruction Cycle?

The instruction cycle is the sequence of steps a CPU follows to execute an instruction. It involves fetching the instruction from memory, understanding it, performing the required operation and updating the CPU state.

This project uses a simplified CPU model to visualize the instruction cycle in action. All five stages — including Memory Access and Write Back — are always performed.

🔑 Key Concepts

  • Instruction – A command given to the CPU.
  • Program Counter (PC) – Holds the address of the next instruction.
  • Instruction Register (IR) – Stores the current instruction.
  • Registers – Small, fast storage locations (R0, R1, R2, R3).
  • ALU – Performs arithmetic and logical operations.
  • Memory – Stores instructions and data.
  • Control Unit (CU) – Decodes and controls the execution.
  • Status Flags – Indicate results (Zero, Carry, Sign).
